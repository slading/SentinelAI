        Detection configuration

        Rules & Detection

        A transparent view of what the console can and cannot manage today.

        Rule catalog unavailable

        Read-only

        The mounted API does not expose a rule catalog or threshold-management endpoint. Detection definitions currently live in server code and configuration files, and separate pipeline paths use different rule sources. No active threshold is editable here.

        A future rule view should identify the executing pipeline, rule version, and effective threshold before offering any change controls.

        Workspace configuration

        Settings

        Configuration is managed by the server; this console does not currently save settings.

        Settings are not connected

        No settings API

        Model selection, thresholds, service levels, and secrets are read from server-side configuration. The mounted API provides no settings read or update route. No editable fields are shown so an unsaved change cannot be mistaken for a saved one.

        Secrets should remain server-side and should never be echoed into this page.
